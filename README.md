 ## Project Overview

This project analyzes sales data to understand product performance, sales trends, quantity sold, and profitability.

## Problem Statement

The objective of this project is to analyze sales data and identify important patterns and business insights that can help improve sales and profitability.

## Dataset Description

The project uses three datasets:
- Sales.csv
- Products.csv
- Customers.csv

The Sales dataset contains order details, quantity, sales amount, and profit.
The Products dataset contains product details and pricing information.
The Customers dataset contains customer names, cities, and regions.

## Tools Used

- Python
- Pandas
- Matplotlib
- Power BI
- Git
- GitHub

## Data Cleaning

The Sales dataset was inspected for missing values and duplicate records.
One duplicate record was removed and the missing Profit value was handled.
The cleaned dataset was saved as Sales_Cleaned.csv.

## Exploratory Data Analysis

EDA was performed to calculate descriptive statistics, analyze correlations, identify outliers, and find important sales and product-level patterns.

## Data Visualizations

Five visualizations were created:
1. Product-wise Sales
2. Product-wise Profit
3. Product-wise Quantity Sold
4. Sales Amount vs Profit
5. Sales Trend Over Time

## Power BI Dashboard

An interactive Sales Performance Dashboard was created using Power BI.

It includes:
- Total Sales KPI
- Total Profit KPI
- Total Quantity KPI
- Four visualizations
- Product Filter
- Customer Filter

## Key Insights

- Total sales were ₹648,800 and total profit was ₹95,450.
- Product 101 was the highest sales contributor.
- Product 102 was the second-highest sales contributor.
- Product 109 had the highest quantity sold.
- Sales Amount and Profit showed a strong positive correlation.

## Recommendations

- Focus marketing and inventory efforts on Products 101 and 102.
- Review pricing and margins of high-volume, low-value products such as Products 109 and 110.

## Conclusion

The project successfully demonstrated the use of data analytics tools to clean, analyze, visualize, and interpret sales data. The findings can support better business decisions related to products, sales, pricing, and profitability.
